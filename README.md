# 格间

安装：`npm ci`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:18260 。

## 故事路线（探险）

「探险」页把散落的题目串成可以慢慢解锁的路线：

- 节点可以要求完成前置题、累计独立解答，或在互斥分支中二选一；地图只展示已开放区域，未解节点仅显示不泄露作品的线索。
- 领取节点奖励会消耗一条完成记录；同一记录全局只能归属一个路线版本，重复进入或刷新不会重复领奖。
- 已领取分支奖励后仍可改道，但互斥奖励会被收回并级联锁定后续节点（地图上注明原因）。
- 两个窗口同时提交时按版本判定，迟到的提交保留为草稿，不会同时领取互斥奖励。
- 存档恢复时按路线版本校验前置关系；循环、缺失题目或版本迁移只隔离受影响节点，成绩保留为「往昔拾遗」，路线不会被误判为通关，终章作品也不会提前揭晓。
